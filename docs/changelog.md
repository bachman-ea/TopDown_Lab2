## Изменения Джуниора
- Увеличена скорость персонажа - Для повышения отзывчивости управления
- Добавлено больше кустов — Для повышения сложности прохождения уровня
- Добавлен последний корридор - Ради драмматичного эффекта
- Добавлена загадка со спрятанным рычагом - Более интересная концовка уровня

## Изменения Сеньора
- Цветовая схема - игра выглядела слишком мрачной, привнёс немного красок.
- Пустоты заполнены травой - слишком много неиспользуемого пространства.
